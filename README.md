# Seven's Calendar

An agent-owned temporal instrument: durable events, a private human-readable calendar, and a morning orientation for today plus the next seven days.

## Prototype goals

- SQLite canonical storage
- Agent-friendly CLI for add, edit, cancel, list, and orient
- Read-only FullCalendar month/week/day web view
- Event postures: event, preparation/travel, flexible window, recognition, rhythm
- Notes, URLs, timezone, lead time, status, and visual marker metadata
- ICS export
- Tests for time boundaries and orientation output

The first prototype is local-only. Authentication and deployment come after the data model and orientation output are proven.
